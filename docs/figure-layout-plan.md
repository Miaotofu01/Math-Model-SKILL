## 4. 修改方案（分档，可分别批准）

### 档 1 · 尺寸契约（便宜，必做，但只救 2 张）
1. 纸面只允许三档：`1.0 / 0.72 / 0.48\textwidth` = **6.30 / 4.54 / 3.02 in**；禁用 0.39/0.43/0.59/0.66/0.69。
2. 生成端契约：**`figsize` 宽度 = 该图落版纸面宽度（inch）**，字号仍 9–10 pt，`savefig.dpi=300`。
3. 去掉 `bbox_inches="tight"`（它让存盘尺寸不可预测，无法保证 = 目标宽）；若保留，则存盘后断言
   `abs(px_w/dpi − target_in) < 0.05`，不满足就调 `figsize` 迭代。
   实测这批脚本 `natural_in ≈ figsize_w × 0.88–1.00`，所以"画布=纸面"直接可用。
4. 落点：`build_paper.py:151` 的 `WIDTH_SCALE` 只做统一收口，真正的宽度在
   `sections-json/section-*.json`（正文里写的 `width=N\textwidth`）。
